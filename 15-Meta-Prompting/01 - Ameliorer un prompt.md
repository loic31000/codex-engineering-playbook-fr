# Améliorer un prompt

## Quand l'utiliser

Quand un prompt est trop vague ou trop long.

## Prompt prêt à copier

```text
Critique ce prompt avant de le réécrire.

Analyse :
- objectif ;
- contexte ;
- ambiguïtés ;
- contraintes ;
- sortie attendue ;
- critères de succès ;
- informations inutiles ;
- contradictions ;
- risques de scope creep.

Puis produis une version améliorée :
- plus courte ;
- plus précise ;
- orientée résultat ;
- sans micro-management du raisonnement ;
- avec conditions d'escalade si décision manquante.
```

## Sortie attendue

Un prompt ou workflow plus robuste.
