# Design a data-dense interface

## When to use it

For dashboards, admin interfaces, tables, and reporting.

## Copy-ready prompt

```text
Design this data-dense interface without sacrificing readability or control.

Evaluate:
- priority columns;
- sorting;
- filters;
- search;
- pagination/virtualization;
- selection;
- bulk actions;
- sticky areas;
- responsive behavior;
- density;
- number/date formatting;
- errors;
- empty states;
- permissions;
- export;
- keyboard accessibility.

Also propose a realistic mobile alternative.

Output: a directly actionable frontend/design recommendation.

If missing information materially changes the result, mark it "to clarify" instead of inventing it.
```

## Expected output

A directly actionable frontend/design recommendation.
