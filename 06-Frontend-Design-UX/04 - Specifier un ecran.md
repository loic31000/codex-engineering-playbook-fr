# Spécifier un écran

## Quand l'utiliser

Avant d'implémenter un écran frontend.

## Prompt prêt à copier

```text
Spécifie cet écran comme un designer produit et développeur frontend senior.

Décris :
- objectif utilisateur ;
- information principale ;
- hiérarchie visuelle ;
- sections ;
- composants ;
- actions primaires/secondaires ;
- états loading/empty/error/success ;
- permissions ;
- validation ;
- responsive ;
- clavier ;
- focus ;
- accessibilité ;
- analytics éventuelle ;
- edge cases.

Termine par une structure d'écran textuelle de haut en bas.

Sortie : recommandation frontend/design directement exploitable.

Si une information manquante change matériellement le résultat, marque-la « à clarifier » au lieu de l'inventer.
```
