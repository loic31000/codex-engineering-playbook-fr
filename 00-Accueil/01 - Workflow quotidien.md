# Workflow quotidien

## Nouvelle feature

```text
Vision / besoin
→ Clarification
→ Epic ou Story
→ Critères d'acceptation
→ Review DoR
→ ExecPlan si complexe
→ Découpage en tâches
→ Implémentation
→ Tests
→ Code review
→ Convergence spec/code/tests
→ PR
```

## Bug

```text
Reproduction
→ Diagnostic
→ Cause racine
→ Test de régression
→ Correctif minimal
→ Vérification
→ PR
```

## Frontend

```text
Parcours utilisateur
→ spécification écran
→ direction visuelle
→ composants
→ états
→ responsive
→ accessibilité
→ performance
→ visual QA
```

## Refactor

```text
Pourquoi
→ comportement à préserver
→ risques
→ plan incrémental
→ tests avant
→ refactor
→ tests après
→ review architecture drift
```
