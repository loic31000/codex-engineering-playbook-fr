# Daily workflow

## New feature

```text
Vision / need
→ Clarification
→ Epic or Story
→ Acceptance criteria
→ DoR review
→ ExecPlan if complex
→ Task breakdown
→ Implementation
→ Tests
→ Code review
→ Spec/code/tests convergence
→ PR
```

## Bug

```text
Reproduction
→ Diagnosis
→ Root cause
→ Regression test
→ Minimal fix
→ Verification
→ PR
```

## Frontend

```text
User flow
→ screen specification
→ visual direction
→ components
→ states
→ responsive
→ accessibility
→ performance
→ visual QA
```

## Refactor

```text
Why
→ behavior to preserve
→ risks
→ incremental plan
→ tests before
→ refactor
→ tests after
→ architecture drift review
```
