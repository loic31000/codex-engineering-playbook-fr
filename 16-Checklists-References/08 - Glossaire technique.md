# Glossaire technique

Ce glossaire normalise les termes utilisés dans la bibliothèque sans chercher à traduire artificiellement tout le vocabulaire logiciel.

| Concept | Forme recommandée |
|---|---|
| scope | scope |
| frontend | frontend |
| rollback | rollback |
| feature flag | feature flag |
| finding | constat |
| blocker | bloquant |
| checks | vérifications |
| state UI | état |
| loading / empty / error | accepté comme vocabulaire UI |
| review | review |
| merge | merge |
| design system | design system |

## Principe

Conserver un terme anglais lorsqu'il est réellement plus précis ou standard dans l'équipe. Préférer le français lorsqu'il améliore la compréhension sans perdre de précision.
