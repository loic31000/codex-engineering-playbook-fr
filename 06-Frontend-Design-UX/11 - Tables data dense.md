# Concevoir une interface data-dense

## Quand l'utiliser

Pour dashboard, admin, tableaux, reporting.

## Prompt prêt à copier

```text
Conçois cette interface dense en données sans sacrifier lisibilité ni contrôle.

Évalue :
- colonnes prioritaires ;
- tri ;
- filtres ;
- recherche ;
- pagination/virtualisation ;
- sélection ;
- bulk actions ;
- sticky zones ;
- responsive ;
- densité ;
- format nombres/dates ;
- erreurs ;
- empty states ;
- permissions ;
- export ;
- accessibilité clavier.

Propose aussi une alternative mobile réaliste.

Sortie : recommandation frontend/design directement exploitable.

Si une information manquante change matériellement le résultat, marque-la « à clarifier » au lieu de l'inventer.
```
