- [ ] critères d'acceptation satisfaits ;
- [ ] tests unitaires nécessaires ;
- [ ] tests intégration nécessaires ;
- [ ] E2E/contract tests nécessaires ;
- [ ] lint/typecheck/build OK si applicables ;
- [ ] sécurité vérifiée ;
- [ ] accessibilité vérifiée si UI ;
- [ ] responsive vérifié si UI ;
- [ ] performance vérifiée si enjeu ;
- [ ] migrations revues ;
- [ ] documentation durable mise à jour ;
- [ ] ADR si nécessaire ;
- [ ] aucun secret ;
- [ ] pas de TODO/FIXME bloquant ;
- [ ] review finale faite ;
- [ ] spec/code/tests/docs convergent.
