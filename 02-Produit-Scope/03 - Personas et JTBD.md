# Personas et Jobs To Be Done

## Quand l'utiliser

Quand les utilisateurs sont encore décrits trop vaguement.

## Prompt prêt à copier

```text
À partir du contexte réel fourni, formalise les principaux profils utilisateurs.

Pour chacun :
- rôle/contexte ;
- objectif principal ;
- Job To Be Done ;
- déclencheur ;
- frustrations ;
- contraintes ;
- niveau d'expertise ;
- décisions importantes qu'il doit prendre dans le produit.

Évite les personas marketing inventés.
N'ajoute aucune donnée démographique sans utilité produit.

Sortie : Des profils fonctionnels utiles aux Stories et à l'UX.

Si une information manquante change matériellement le résultat, marque-la « à clarifier » au lieu de l'inventer.
```
