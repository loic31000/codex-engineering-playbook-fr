# Choose the right prompt

| Situation | Recommended prompt |
|---|---|
| New project | Project bootstrap |
| Existing repository | Analyze existing repository |
| Vague feature | Clarify a Story |
| Large feature | Split a large feature |
| Technical choice | Propose architecture / ADR |
| Frontend to design | Flow → screen → design system → components |
| UI to improve | UX/UI review |
| Bug | Bug diagnosis |
| Refactor | Controlled refactor |
| Before coding | Story Ready Review |
| Before merge | Final review + convergence |
| Sensitive security | Feature security review |
| Poor prompt | Improve a prompt |
