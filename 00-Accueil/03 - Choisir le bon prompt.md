# Choisir le bon prompt

| Situation | Prompt conseillé |
|---|---|
| Nouveau projet | Bootstrap projet |
| Repository existant | Analyse repository |
| Feature vague | Clarifier une Story |
| Grosse feature | Découper une grosse feature |
| Choix technique | Proposer architecture / ADR |
| Frontend à concevoir | Parcours → écran → design system → composants |
| UI à améliorer | Review UX/UI |
| Bug | Diagnostic bug |
| Refactor | Refactor contrôlé |
| Avant codage | Story Ready Review |
| Avant merge | Review finale + convergence |
| Sécurité sensible | Security review |
| Mauvais prompt | Améliorer un prompt |
