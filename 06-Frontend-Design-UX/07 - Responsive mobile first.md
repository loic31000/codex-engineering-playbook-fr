# Conception responsive mobile-first

## Quand l'utiliser

Quand un écran doit fonctionner de mobile à desktop.

## Prompt prêt à copier

```text
Revois cet écran en mobile-first.

Pour chaque breakpoint logique :
- priorité du contenu ;
- ordre ;
- largeur ;
- grille ;
- navigation ;
- tableaux/listes ;
- actions ;
- overlays ;
- formulaires ;
- typographie ;
- touch targets ;
- overflow.

Ne te contente pas de « tout empiler ».
Explique ce qui change réellement dans la composition entre petit et grand écran.
```
