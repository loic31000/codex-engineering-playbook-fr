# Review accessibilité WCAG 2.2

## Quand l'utiliser

Pour une UI avant merge ou lors de la conception.

## Prompt prêt à copier

```text
Agis comme un spécialiste accessibilité web.

Revois cette interface vis-à-vis de WCAG 2.2, avec un objectif AA sauf contrainte différente.

Examine :
- structure sémantique ;
- headings ;
- landmarks ;
- labels ;
- erreurs ;
- navigation clavier ;
- focus visible ;
- ordre de focus ;
- contrastes ;
- zoom/reflow ;
- touch targets ;
- alternatives textuelles ;
- status messages ;
- dialogs ;
- formulaires ;
- drag/drop ;
- authentification accessible ;
- contenu animé ;
- préférences reduced motion.

Classe les problèmes :
- bloquant ;
- important ;
- amélioration.

Donne une méthode de vérification pour chaque finding.
```
