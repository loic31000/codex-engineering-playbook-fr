# Frontend checklist

## Functional
- [ ] happy path
- [ ] errors
- [ ] loading
- [ ] empty
- [ ] permissions
- [ ] retry

## UX
- [ ] clear hierarchy
- [ ] clear primary action
- [ ] user feedback
- [ ] understandable copy
- [ ] no unnecessary friction

## Responsive
- [ ] mobile
- [ ] tablet when relevant
- [ ] desktop
- [ ] overflow
- [ ] touch targets

## Accessibility
- [ ] semantic HTML
- [ ] labels
- [ ] keyboard
- [ ] visible focus
- [ ] focus order
- [ ] contrast
- [ ] accessible errors
- [ ] reduced motion
- [ ] zoom/reflow

## Design system
- [ ] tokens
- [ ] spacing
- [ ] typography
- [ ] semantic colors
- [ ] existing components reused
- [ ] no unnecessary ad hoc variants

## Performance
- [ ] images
- [ ] fonts
- [ ] unnecessary JS
- [ ] rendering
- [ ] LCP
- [ ] INP
- [ ] CLS

## Tests
- [ ] components
- [ ] integration
- [ ] critical E2E
- [ ] accessibility
