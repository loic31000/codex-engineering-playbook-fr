# Concevoir un formulaire robuste

## Quand l'utiliser

Pour login, checkout, onboarding, settings, etc.

## Prompt prêt à copier

```text
Conçois ce formulaire pour minimiser erreurs et friction.

Définis :
- ordre des champs ;
- groupement ;
- labels ;
- aide ;
- champs requis ;
- validation ;
- validation serveur/client ;
- erreurs inline/globales ;
- préservation des données ;
- submit ;
- double-submit ;
- loading ;
- succès ;
- clavier/mobile ;
- autofill ;
- accessibilité.

N'utilise pas de placeholder comme seul label.

Sortie : recommandation frontend/design directement exploitable.

Si une information manquante change matériellement le résultat, marque-la « à clarifier » au lieu de l'inventer.
```
