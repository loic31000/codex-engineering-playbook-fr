## Accessibilité

Pour le Web, utiliser WCAG 2.2 comme base actuelle.

Principes :
- perceptible ;
- utilisable ;
- compréhensible ;
- robuste.

## Performance frontend

Core Web Vitals :
- LCP ;
- INP ;
- CLS.

Les seuils doivent être mesurés sur de vraies données ou des outils de performance adaptés, pas simplement supposés.
