# Review UX/UI critique

## Quand l'utiliser

Quand un écran existe mais semble difficile ou incohérent.

## Prompt prêt à copier

```text
Fais une critique UX/UI structurée de cette interface.

Évalue :
- clarté de l'objectif ;
- hiérarchie ;
- charge cognitive ;
- découvrabilité ;
- affordances ;
- feedback ;
- cohérence ;
- erreurs ;
- densité ;
- navigation ;
- mobile ;
- accessibilité ;
- confiance ;
- friction.

Pour chaque problème :
- preuve observable ;
- impact utilisateur ;
- priorité ;
- correction minimale ;
- option plus ambitieuse si utile.

Évite les goûts personnels non justifiés.
```
